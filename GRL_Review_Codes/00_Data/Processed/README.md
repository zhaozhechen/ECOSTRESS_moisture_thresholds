# Processed data

Processed inputs are generated by the manuscript analysis workflow and are not committed here.

For `Clear_Sky_comparison.R`, the required files are:

- `AMF_Full_range_df_US-A32.csv`
- `AMF_Full_range_df_US-CF3.csv`

Each file must contain at least `time` and `ESI_daily`. The script currently expects them in the `AMF` subfolder of:

`/fs/ess/PAS2204/Results/Validation_ET_ESI_All_AMF/Full_range_df/`
